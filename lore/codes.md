---
title: "Archive codes"
order: 2
summary: "INSTITUTION/MEDIUM/YEAR/NUMBER, and what each part means."
---

Every Archive object carries a code in the form `INSTITUTION/MEDIUM/YEAR/NUMBER`, for example `UBK/AV/1996/0003`, the UBIK ONE launch. Numbers run per institution per year and never repeat. Gaps are allowed, and say something.

The code belongs to the catalogue. It is never printed on the object itself.

## Institutions

| Code | Institution |
|---|---|
| `MSA` | Ministry of State Affairs |
| `BSV` | Border Service (also issues passports) |
| `SA` | State Archive |
| `UNT` | Ubikistan National Television |
| `MCA` | Ministry of Culture |
| `MMA` | Ministry for Machine Affairs |
| `NICC` | National Institute for Computation and Communications (1981); from 1990 the research institute of UBIK Systems, under its old name |
| `UBK` | UBIK Systems Corporation, a public enterprise of the Republic (1990) |
| `RES` | Reserve of Ubikistan (currency) |
| `PTT` | State Post |
| `SPC` | Sporting Committee |
| `RSP` | Register of Synthetic Persons |

| Code | Medium |

| `PP` | passport |
