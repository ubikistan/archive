The Border Service's receipt for the stamps and seals returned from the Embassy when it closed in 2020.

A typed form headed BORDER SERVICE · RETURN OF CONTROLLED ITEMS · EMBASSY, in four columns: ITEM · ISSUED · RETURNED · NOTE. ENTRY stamp, violet: 3, 3. TRANSIT stamp: 2, 2. VOID stamp: 1, 1. DUPLICATE stamp: 1, 0, with the note "not found". Ink pads: 6, 4. Embassy seal: 1, 1. Visitors' book: 1, 1, "to State Archive".

Below the table, typed: "Services transferred to the network from this date. Duplicate function not required." Signed by the head of chancery and countersigned "for the Commissioner" with the initial A. The stamp EMBASSY · CLOSED is struck twice, the second impression lower and fainter.

One line has been added in pencil at the foot: "Server room: not inventoried. Key held by Commissioner." It is not signed.

Received at the inspection office at the Border Gate. The DUPLICATE stamp has not been returned since. The visitors' book is not in the State Archive under any catalogue number it has been asked about.
