The first sheet of the output from run F-6/86-112, the Station 6 Incident. Windows, confidences and actions are blank.

The fragments read NETWORK / PERSONAL, STATE FITS HERE, EVERYWHERE, CITIZEN / NON-BIOLOGICAL, EXTERNAL SIGNAL and REOPENING. The run printed 17 metres of paper. The State Archive holds this sheet; where the rest is, the Archive does not say.

Disputed: the sheet was sealed in 1986 and first described in public after 2008. Whether it predates the products it seems to name cannot be shown from the paper.
